# One Letter for Your Day

This entry is a compact Node 22 TypeScript program that writes exactly one letter, G, to `/output/entry.txt`, where G stands for the word "gobsmacked", capturing a day that left the sender utterly astonished and perfectly embodying the sheer surprise of an unforgettable moment.

## Run

You can execute the program locally using `node main.ts`, which produces an output file that is exactly one byte long.
